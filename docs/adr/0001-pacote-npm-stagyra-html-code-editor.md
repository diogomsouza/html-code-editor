# Pacote NPM @stagyra/html-code-editor

O pacote publicavel sera nomeado como `@stagyra/html-code-editor` e o seletor publico sera `<stagyra-html-code-editor>`. O escopo `@stagyra` mantem consistencia com `@stagyra/angular-magnetic-menu`, reduz conflito com nomes globais no npm e separa o contrato publico do seletor interno usado no MyStocks.

## Considered Options

- `html-code-editor`
- `@stagyra/html-code-editor`

## Consequences

A instalacao documentada sera `npm install @stagyra/html-code-editor`, e a conta ou organizacao npm `@stagyra` precisa existir antes da publicacao.
